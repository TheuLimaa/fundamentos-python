# Fundamentos de Python

Reforçando a base e a sintaxe de Python — condicionais, loops, listas e
dicionários, funções, módulos e tratamento de erros — com exercícios que eu
mesmo resolvo, sem código pronto de IA.

Percebi, construindo meus outros projetos (`cotacoes-financeiras`,
`tratamento-dados-sql`), que estava dependendo demais de pedir código pronto
pra IA, sem entender o suficiente pra escrever sozinho. Este projeto existe
pra fechar essa base.

## Trilha de estudo (em ordem)

1. `01_condicionais.py` — if / elif / else
2. `02_loops.py` — for / while
3. `03_listas_dicionarios.py` — listas e dicionários
4. `04_funcoes.py` — funções (def, parâmetros, return)
5. `05_modulos_imports/` — como dividir código em arquivos que se importam
6. `06_tratamento_erros.py` — try / except

## Como uso isso

Cada arquivo tem o conceito explicado em comentário, e os exercícios logo
abaixo, sem resposta pronta. Escrevo o código, rodo (`python 01_condicionais.py`,
por exemplo), erro, ajusto. Só peço ajuda pra entender um conceito ou destravar
um erro — não pra resolver por mim.
